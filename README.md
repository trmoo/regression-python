# 🚲 자전거 대여량 회귀 분석 실습실

© 2026 티쳐무 · 모든 권리 보유 · 학교 수업 목적으로만 이용해 주세요.

고등학교 「데이터 과학」 교과서 114~121쪽 실습 **「날씨와 자전거 대여량은 어떤 관계가 있을까?」** 를
설치 없이 브라우저에서 **진짜 파이썬**(pandas · seaborn · statsmodels · scikit-learn)으로 따라 하는 실습실입니다.

👉 **바로 열기: https://trmoo.github.io/regression-python/**

## 무엇을 하나

공유 자전거의 시간별 대여 기록 `smtrain.csv`(10,886줄)로 대여량을 예측하는 회귀 모델을 만듭니다.
교과서 노트북의 차례를 그대로 따라갑니다.

| 단원 | 레슨 | 하는 일 |
|---|---|---|
| 0 시작 | 문제와 데이터 | 문제 상황 · 열 17개의 뜻 · **`count` 는 log(대여 수 + 1) 이라는 것** |
| Ⅰ 탐색과 전처리 | 불러오기 · 이상치 · 변수 고르기 · 상관·히트맵 | `read_csv` · `info` · `describe` · 상자그림 · `sns.pointplot` · `corr` · `sns.heatmap` · 상관 0.3 이상 고르기 |
| Ⅱ 통계적 회귀 | OLS 와 summary · 회귀식·예측 | `sm.add_constant` · `sm.OLS(y, X).fit()` · 결과표 읽기 · 유의하지 않은 변수 빼기 · 예측 |
| Ⅲ 기계학습 회귀 | 데이터 나누기 · 학습·평가 · 🔬 더 해 보기 | `train_test_split` · `LinearRegression` · `predict` · `mean_squared_error` · hour 를 범주로 |
| Ⅳ 정리 | 정리 | 두 방법 견주기 · 처음부터 끝까지 한 셀 · 한 장 정리 |

- **빈칸 셀** 33개(빈칸 38칸) — 빈칸을 채워 실행하면 채점합니다. 글자가 달라도 실행 결과가 같으면 정답입니다(예: `y_test[:5]` 와 `y_test.head()`).
  힌트는 세 단계(설명 → 첫 글자 → 정답 넣기)입니다.
- **고르기 문제** 57개 — 결과를 해석하는 문제·실행하기 전에 짐작해 보는 문제 19개, 레슨 끝 확인 문제 38개.
- **그림 도구** 11가지 — 실제 대여 수와 로그 값의 분포 · 상자그림 해부 · 시간대별 평균 · 상관계수 기준값 바꾸기 ·
  결과표(summary) 눌러 읽기 · 회귀식 계산기 · 학습용/평가용 나누기 · 실제값 vs 예측값 · 직선 vs 시각별 · MSE 견주기.
- **자유 실험 칸** — 레슨마다 하나씩, 위 셀에서 만든 변수로 마음대로 코드를 쳐 볼 수 있습니다.

## 쓰는 법

1. 주소를 열고 셀의 **[▶ 실행]** 을 누르면 파이썬 엔진(약 40MB)을 받아 켭니다. 처음 한 번은 30초~1분쯤 걸립니다.
2. 위에서부터 빈칸을 채우며 실행합니다. 주소 끝에 `#ols/fit` 처럼 붙이면 그 레슨으로 바로 갑니다.
3. 수업 시연에는 주소 끝에 `?demo` 를 붙이면(예: `…/regression-python/?demo#ml/train`) 정답을 채워 위에서부터 실행해 둡니다.

- 인터넷이 끊겨 엔진을 받지 못하면 **미리 계산해 둔 결과**(같은 판의 파이썬으로 돌린 것, 그래프 포함)를 보여 주고 빈칸은 글자로 채점합니다.
- 학생 이름·학번을 받지 않습니다. 빈칸 답과 통과 표시만 이 브라우저에 남고, 오른쪽 위 **[🧹 내 기록 지우기]** 로 지웁니다.

## 코랩과 다른 점

- 이 실습실은 Pyodide 314.0.7(파이썬 3.14 · pandas 3.0 · statsmodels 0.14.6 · scikit-learn 1.8 · matplotlib 3.10 · seaborn 0.13.2)로 돕니다.
  코랩(pandas 2.2)과 견주면 `info()` 에서 글자 열이 `object` 대신 `str` 로 찍히는 정도가 다르고, 숫자 결과는 같습니다.
- 코랩에서는 맨 처음 `files.upload()` 로 `smtrain.csv` 를 올려야 하지만, 여기에는 파일이 이미 들어 있습니다.
- 그래프의 글자는 영어만 씁니다. 한글 제목을 넣으면 글꼴이 없어 네모로 보입니다(코랩도 글꼴을 따로 설치해야 합니다).

## 만들기 (교사·개발자용)

```bash
npm install
npm start          # 개발 서버
npm test           # node 의 Pyodide 로 레슨 46셀 재현 · 다른 정답 · 엉뚱한 답 · 설명 속 숫자 (약 1분)
npm run build      # 문법·저작권 점검 → dist/index.html 한 파일(약 1.6MB) → 빌드 결과 점검
npm run golden     # 레슨을 고친 뒤 미리 계산한 결과(src/data/golden.json)를 다시 만든다
```
